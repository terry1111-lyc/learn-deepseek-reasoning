# 离线实验指南

在仓库根目录运行。仅依赖 Python 3.10+ 标准库，无安装步骤、API 费用或模型下载。

## 1. GRPO 的一个组成部分

```bash
python3 examples/s01_grpo.py
```

预期：奖励 `[1,0,1,0]` 的优势四舍五入为 `[1,-1,1,-1]`；全对与全错两组都为零。概率比率为 1.5 时，正优势的裁剪项为 1.2，负优势为 -1.5。

尝试改成 `[0,0,0,1]`。解释最后一个候选为何获得更大的相对优势。该脚本没有计算真实 token 概率、KL、损失反向传播或参数更新，不是完整 GRPO。

## 2. MoE 路由

```bash
python3 examples/s02_moe.py
```

无偏置时选中 `[0,1]`，权重约 `[0.6667,0.3333]`，输出约 `2.8667`。给专家 2 加选择偏置后选中 `[2,0]`，权重 `[0.25,0.75]`，输出 `1.2`。

注意：专家 2 的原分数仍然是 0.2，不是加偏置后的 0.7。这里用标量函数代替神经网络，只有路由与加权组合的教学意义。

## 3. MLA 缓存算术

```bash
python3 examples/s03_mla_cache.py
```

预期：在脚本的假设下，展开缓存 `19.0625 GiB`，压缩缓存约 `0.2681 GiB`，元素数比约 `71.1111x`。这些是公式计算值，不是显存测量。

将 tokens 加倍，两项都加倍；比值不变。不要据此预测总显存、tokens/s 或端到端延迟。脚本也不是 V4 缓存估算器。

## 4. 正确候选不等于正确交付

```bash
python3 examples/s04_evaluation.py
```

预期：pass@1 为 0.4，pass@2 为 0.7，pass@5 为 1.0；多数票答案 41，判定错误。`[41,42]` 平票时函数返回 `None` 表示弃权。

这是一个题目的构造例子。真实报告应逐题计算再聚合，说明题目数量、采样预算、去重与答案归一化方式。该程序不构成任何模型性能排名。

## 5. 模型与工具之间的应用循环

```bash
python3 examples/s05_harness.py
```

预期消息角色顺序：`user → assistant → tool → assistant`，最终答案 `42`。模拟模型被硬编码为请求 `add(19,23)`；它不是可以回答任意问题的模型。

工具只支持有界整数加法；未知工具、错误参数会抛异常，超出循环步数会停止。生产框架还要处理工具调用 ID、并发、流式解析、重试、权限、持久化等；此处没有宣称实现这些功能。

## 验证

```bash
python3 -m unittest discover -s tests -v
```

测试覆盖零方差、裁剪符号、选择偏置与权重分离、缓存线性增长、评测边界、非法工具和无法结束的循环。
